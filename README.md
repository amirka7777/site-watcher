# Site-Watcher

Высокопроизводительный многопоточный сервис на языке **Go** для фонового мониторинга доступности веб-сайтов (Uptime Checker). Сервис динамически управляет проверками с помощью горутин и каналов, замеряет скорость ответа сайтов и сохраняет всю историю в базу данных **SQLite3**.

---

## Эндпоинты API

### 1. Добавить сайт на мониторинг
* **Метод:** `POST`
* **URL:** `/sites`
* **Тело запроса:** JSON с адресом сайта и индивидуальным интервалом проверки (в секундах).
* **Пример запроса:**

```bash
curl -X POST http://localhost:8080/sites \
     -H "Content-Type: application/json" \
     -d '{"url": "[https://google.com](https://google.com)", "interval_seconds": 12}'
```
### 2. Получить список всех сайтов
* **Метод:** `GET`
* **URL:** `/sites`
* **Пример запроса:**

```bash
curl -X GET http://localhost:8080/sites
```

### 3.Получить история проверок сайта (Чек-логи)
* **Метод:** `GET`
* **URL:** `/sites/logs`
* **Query-параметры (Обязательный):** `site_id (integer) — идентификатор сайта.`
* **Описание:** `Возвращает лог проверок (статус-код, время ответа в мс, флаг доступности) в порядке убывания.`
* **Пример запроса:**
```bash
curl -X GET "http://localhost:8080/sites/logs?site_id=1"
```
